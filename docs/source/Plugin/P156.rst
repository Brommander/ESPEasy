Supported hardware
------------------

Supports any device communicating over Modbus TCP (Modbus over Ethernet/WiFi).
Up to 4 registers can be read per task, each with an independent poll interval.

Tested devices:

* Kostal Plenticore inverter (Port 1502, Unit ID 71, Function 03, Float IEEE754)
* Sungrow SH hybrid inverter (Port 502, Unit ID 1, Function 04, U16/S16/U32/S32)
* Varta ELM storage system (Port 502, Unit ID 255, Function 03, U16/S16/U32)
* Any Modbus TCP device with Function 03 or 04

Precautions
-----------

The device must be reachable on the local network before the plugin attempts
a connection. The plugin automatically waits for WiFi to be connected before
making any TCP connection attempt.

Modbus register addresses in this plugin use **PDU addressing** (0-based).
If your device documentation uses 4xxxxx notation, subtract 400001 from the
address shown (e.g. 400100 → 99).

Hardware
--------

No additional hardware required. The device must be connected to the same
network as the ESP32 via Ethernet or WiFi.

Configuration
-------------

**Name** A unique name for the task (example: **ModbusMeter**).

**Enabled** The device can be enabled or disabled.

Sensor
^^^^^^

Connection
""""""""""

**IPv4 Address** IP address of the Modbus device.

**Port** TCP port of the Modbus device. Typical values: 502 or 1502.

**Unit ID** Modbus unit identifier (slave address). Range: 1–255.

**Function Code** Modbus read function:

* ``03`` - Read Holding Registers
* ``04`` - Read Input Registers

Pause Groups
""""""""""""

Four independent pause groups control the poll interval for each query.
Groups 1 and 2 use steps of 100 ms (max 25500 ms).
Groups 3 and 4 use steps of 1000 ms (max 255 s).

.. csv-table::
  :header: "Group", "Step size", "Max interval"
  :widths: 5, 8, 10

  "Group 1", "100 ms", "25500 ms"
  "Group 2", "100 ms", "25500 ms"
  "Group 3", "1000 ms", "255 s"
  "Group 4", "1000 ms", "255 s"

Queries (4 Values)
""""""""""""""""""

Each of the 4 output values is configured independently:

**Register Address** PDU address (decimal, 0--65535).

.. note::

   4xxxxx notation: subtract 400001 (e.g. 400100 -> 99).

**Data Type** Format of the register data:

.. csv-table::
  :header: "Data Type", "Size", "Description"
  :widths: 8, 5, 20

  "U16", "2 bytes", "Unsigned 16-bit integer"
  "S16", "2 bytes", "Signed 16-bit integer"
  "U32", "4 bytes", "Unsigned 32-bit integer (big-endian word order)"
  "S32", "4 bytes", "Signed 32-bit integer (big-endian word order)"
  "Float", "4 bytes", "IEEE 754 single precision (e.g. Kostal)"
  "U32 WS", "4 bytes", "Unsigned 32-bit, word-swapped (low word first, e.g. Varta)"
  "S32 WS", "4 bytes", "Signed 32-bit, word-swapped (low word first)"

**Pause Group** Assigns this query to one of the four pause groups.

.. note::

   Word-swapped types (U32 WS, S32 WS) are required for devices that send the
   low word before the high word, such as the Varta ELM storage system.

.. include:: DataAcquisition.repl

* **Interval**: Controls how often values are published via events/MQTT.
  The actual poll rate is controlled by the Pause Group settings.

Output
^^^^^^

Output values
"""""""""""""

.. csv-table::
  :header: "Value", "Description"
  :widths: 5, 30

  "Value 1", "Result of Query 1 register read"
  "Value 2", "Result of Query 2 register read"
  "Value 3", "Result of Query 3 register read"
  "Value 4", "Result of Query 4 register read"

Scaling factors can be applied using the ESPEasy formula field
(e.g. ``%VALUE%*0.1`` for Sungrow registers that use 0.1 unit steps).
